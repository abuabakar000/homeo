# Homeo Dr. Ateeq-ur-Rehman Butt - Okara Clinic Website

A modern, high-performance, bilingual (Urdu & English) single-page website for **Homeo Dr. Ateeq-ur-Rehman Butt (D.H.M.S • R.H.M.P)** located in **Okara, Pakistan**, built with **Next.js 14**, **Tailwind CSS**, and **Noto Nastaliq Urdu**.

## 🌟 Key Features
- **Bilingual & RTL-Ready**: Urdu typography with `Noto Nastaliq Urdu` font and English translations.
- **Hero Profile**: Doctor qualifications, professional portrait, and direct WhatsApp & Call actions.
- **Key Specializations**: Men's vitality, infertility counseling, free asthma care, joint pain, digestive, and kidney stone treatments.
- **Tila Lajawab & Medicine Home Delivery**: Dedicated showcase for Tila Lajawab with all-Pakistan home delivery.
- **Instant 1-Click WhatsApp & Call CTAs**: Pre-filled appointment and inquiry messages for phone `0323-6392323`.
- **Location & Google Maps**: Clinic address (Chungi No. 7, Firdous Town, Street No. 2, Okara) with copy button and Google Maps directions.
- **Responsive & Mobile-Optimized**: Persistent floating action bar for mobile devices.
- **Vector Favicon**: Crisp medical & homeopathic emblem.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
